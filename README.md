# 🏥 AI Hospitaling

An AI-powered hospital management system built with React, Node.js, Express, and MongoDB.

## 🚀 Live Demo

👉 **[Visit AI Hospitaling](https://ai-hospitaling-al404tlq8-lokesh-1b7f.vercel.app/)**

### 🔗 Deployment

- **Frontend:** [Vercel](https://ai-hospitaling-al404tlq8-lokesh-1b7f.vercel.app/)
- **Backend API:** [Render](https://ai-hospital-server.onrender.com/)

## ✨ Features

- 👤 Patient Registration & Login
- 👨‍⚕️ Doctor Management
- 📅 Appointment Booking
- 🏥 Hospital Management
- 🤖 AI Health Chatbot
- 🔐 JWT Authentication
- 📊 Admin Dashboard
- 🗓️ Doctor Availability Management

## 🛠️ Tech Stack

### Frontend
- React.js
- Axios
- React Router
- Tailwind CSS

### Backend
- Node.js
- Express.js
- MongoDB
- JWT Authentication

### Deployment
- Vercel – Frontend
- Render – Backend
